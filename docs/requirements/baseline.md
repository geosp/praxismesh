# Incorporated Phase 0/1 requirement baseline

The following historical requirement texts are incorporated by reference as the
regression baseline for existing behavior. Retiring OpenSpec tooling does not
retire these guarantees. New approved implementation plans must preserve them or
explicitly identify amendments, rationale and regression coverage. The project
plan remains authoritative for scope and gates (§4.16).

The original files are retained unchanged at their existing paths so completed
review, RFC and phase evidence links remain valid. Future requirement changes
belong in docs/plans, not in the historical files. Archived proposals are evidence
of past changes rather than new work queues.
