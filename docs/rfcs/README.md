# RFCs

Proposed designs, written and independently reviewed **before** a phase or material change is implemented (plan §4.17).

- **Name:** `phase-N-<topic>.md` (for example `phase-0-local-infrastructure.md`), or `general-<topic>.md` for work not tied to a phase.
- **Template:** [full RFC](../templates/rfc.md) from Phase 3A onward and for material changes; [short RFC](../templates/rfc-short.md) for the light-tier Phases 0-2.
- **How:** the `docs-design` skill drafts the RFC on a draft pull request; the `review-design` skill reviews it in a fresh session. Status moves from `draft` to `proposed` to `accepted`.
