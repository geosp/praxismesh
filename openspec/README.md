# Historical OpenSpec records

OpenSpec is retired from the active PraxisMesh development workflow by project
plan revision 2.12. Retain specs and archived changes unchanged for provenance and
completed-phase evidence. Their existing guarantees are explicitly incorporated
by [the regression baseline](../docs/requirements/baseline.md).

New work uses [implementation plans and the Skill Central suite](../docs/development/planning.md).
Do not regenerate skills, initialize a new OpenSpec target, or create new changes here.
